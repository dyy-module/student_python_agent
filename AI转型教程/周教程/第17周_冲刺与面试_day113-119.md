## Day113(周一,7h)· 面试题库 I:RAG 召回优化排查 + Agent 循环护栏

冲刺周第一天,先把最硬的两类弹药铸好。面试官问 RAG 与 Agent,很少问"API 怎么调",而是问"召回差怎么办、Agent 死循环怎么办"——这类排查与工程化题,恰好是你在项目1(商品知识库导购问答)与差异化面板里真实做过的事,今天把它们整理成"能脱稿讲"的题库。

💡 冲刺者速读:面试答题 ≈ 你写技术方案的套路——先结论、再分层排查、最后给数据佐证;RAG 召回排查 ≈ 前端排查"白屏":从数据源→切分→embedding→检索→rerank 逐层定位,而不是上来就改代码;Agent 循环护栏 ≈ 你给轮询设的最大重试次数 + 超时兜底,思想完全一致。

### 学习内容

- RAG 召回优化排查链路:先用第08周评测集定位(命中率低是检索问题还是生成问题)→逐层排查切分粒度/embedding 模型/混合检索/rerank/引用标注
- Agent 循环护栏:最大步数(max_steps)、单步超时、工具异常兜底(try/except)、死循环识别与人工接管
- STAR 答题结构(背景-任务-行动-结果)与"结论→分层→佐证"三段式
- 项目佐证绑定:项目1 的命中率/召回数据、评测集规模、Agent 面板轨迹截图
- 追问预判:面试官常见的二阶追问(如"rerank 提升多少?怎么量的?")

### 讲解

结论先行:弹药题的答题框架统一为"结论 → 分层排查 → 项目佐证 → 量化结果"四步——先给结论性判断,再展示系统化排查路径,最后落到自己项目的真实数据。RAG 召回差的排查从评测集切入(先分清"检索没召回归"还是"召回了没答好"),Agent 死循环的防线是"步数护栏 + 异常兜底 + 人工接管"三层。以下是作答要点框架(不含答案全文,答案由你结合项目数据本人撰写):

| 题目方向 | 作答要点框架(骨架,非答案) |
| -------- | ------------------------------ |
| 召回差怎么排查 | 评测集定位 → 切分 → 向量化 → 混合检索 → rerank → 引用,逐层给证据 |
| rerank 的价值与代价 | 精排提升命中 vs 延迟/成本,给出你项目的实测取舍 |
| Agent 死循环怎么防 | 最大步数 → 异常兜底 → 观察结果校验 → 人工接管,绑定面板轨迹 |
| 护栏触发后怎么办 | 降级回复/记录轨迹/提示人工,绑定你的兜底实现 |

## Day114(周二,7h)· 面试题库 II:流式前端工程 + token 成本优化 + 效果评估

今天铸剩下三类弹药,它们分别是你的"前端主场"(流式工程)、"成本意识"(token 优化)与"效果意识"(评估)——BOSS 直聘研究院指 AI 应用岗看重"用 AI 解决实际问题并交付可衡量结果",这三类题正是"可衡量结果"的答法。

💡 冲刺者速读:SSE 断线重连 ≈ 你做过的轮询降级与 WebSocket 心跳重连,EventSource 自带自动重连、fetch 流要手动续传;乐观渲染 ≈ 你发请求前先更新 UI、失败再回滚的套路;token 成本优化 ≈ 前端资源优化里的"缓存 + 按需加载":缓存减少重复计算,小模型路由 = 图片用 webp、关键图才上原图。

### 学习内容

- 流式前端工程三件套:SSE 断线重连(EventSource 自动重连/Last-Event-ID、fetch 流手动重连)、中断(AbortController)、乐观渲染(先上屏再校对/回滚)
- token 成本优化:prompt/上下文缓存、会话历史裁剪(呼应第09周记忆窗口)、小模型路由与降级(简单意图走小模型、复杂任务走大模型)
- 效果评估:评测集构建(30-50 条)、命中率/召回、LLM-as-judge(用强模型按标准评弱模型输出)
- 三类题的项目佐证:第10-12周流式组件实践、第05-09周成本与评测数据、第08周评测报告
- 追问预判:断线后消息会不会重复?judge 可靠吗?路由误判怎么办?

### 讲解

结论先行:流式工程题的答法是"可靠性叙事"——断线重连、中断、乐观渲染各给机制 + 你项目里的真实取舍;成本题的答法是"两板斧"——缓存(减少重复 token)与路由(任务分级),并给出你项目的成本数据;评估题的答法是"先有评测集再谈效果",LLM-as-judge 要说清评分标准与人工抽检校准。以下是作答要点框架(答案正文由你本人撰写):

| 题目方向 | 作答要点框架(骨架,非答案) |
| -------- | ------------------------------ |
| SSE 断线重连怎么做 | EventSource 自动重连 vs fetch 流手动重连;消息幂等/续传策略;绑定你的实现 |
| 流式渲染的性能取舍 | 逐字 DOM 更新节流、Markdown 增量渲染、打字机与重排的关系 |
| token 成本怎么降 | 缓存命中(系统提示/少变上下文)、历史裁剪、小模型路由 + 降级,给月成本数据 |
| 效果怎么评估 | 评测集构建 → 命中率/召回 → LLM-as-judge 标准 + 人工抽检校准 |

## Day118(周六,7h)· 模拟面试 + 复盘回填

今天是"实战彩排"日:完成至少 2 场模拟面试(1 场 AI 扮演面试官 + 1 场真人或录音自测),把暴露的卡壳点当场回填到题库与讲解稿——模拟的价值不在"练过",而在"每一场都让下一场更强"。

💡 冲刺者速读:模拟面试 ≈ 上线前的灰度验证:先小流量(AI 面试官/录音)暴露问题,再全量(真人/真面试);复盘回填 ≈ 你的 bug 回归流程——每个卡壳点建一条"缺陷单",修完(回填题库/改稿)才算关闭;二阶追问 ≈ 边界测试:面试官专挑你没准备的分支问。

### 学习内容

- 模拟面试流程:自我介绍(2 分钟)→ 项目深挖(按讲解稿)→ 弹药五类抽题(RAG/Agent/流式/成本/评估)→ 前端老本行 → 反问环节
- 复盘回填机制:卡壳题 → 回填题库补要点;讲不顺的段落 → 修订讲解稿;答不上的追问 → 补项目佐证或明确"未实践过"的边界
- 用 AI 当面试官:让 AI 按岗位 JD 出题、二阶追问、按 4 维度(表达完整性/技术深度/项目佐证/诚信边界)打分并给改进方向(评分,不代写答案)
- 反问环节设计:问团队模型侧工程场景、评测体系、业务域(判断是否真 AI 岗,呼应伪 AI 岗甄别)
- 英语环节:英文自我介绍/JD 关键句演练(慢变量)

### 讲解

结论先行:模拟面试的唯一 KPI 是"关闭卡壳点"——每场结束必须产出三样东西:回填题库的题、修订的讲稿段落、明确的能力边界(哪些坦承未实践)。用 AI 面试官时给它岗位 JD 与你的简历要点,要求它追问到底,比自问自答更接近真实压力。以下是复盘回填的流程框架(复盘正文由你本人撰写):

| 复盘回填项 | 处理方式 |
| ---------- | -------- |
| 卡壳题/答错的题 | 回填对应题库分册,补要点框架与项目佐证 |
| 讲不顺的项目段落 | 修订讲解稿,砍掉记不住的细节、补量化结果 |
| 完全没准备的追问 | 二选一:能补佐证的补;不能的写进"能力边界"话术(认知级/未实践) |
| 表达问题(语速/结构) | 下一场录音对照,检查"结论先行"是否做到 |
