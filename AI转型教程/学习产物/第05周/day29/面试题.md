# 标准答案(2026-11-15)

## Q1 标准答案
venv 解决的是依赖环境**全局唯一**的问题:全局安装时所有项目共用同一份 site-packages,同一个包只能存在一个版本——项目 A 要 openai 1.x、项目 B 要 2.x 就会互相覆盖;升级/卸载任何一个包都会波及所有项目,这就是"环境污染"。venv 为每个项目建独立环境:**独立 site-packages + 指向基础 Python 的解释器指针**,装/卸/升级只影响本项目,项目间互不干扰。
除隔离外还要补两点:
1. **可复现**:配合 day22 的 requirements.txt 锁定版本,换机器/同事协作时一条 `pip install -r requirements.txt` 还原同一套环境,"在我机器上能跑"变成"在哪台机器都能跑"。
2. **权限与系统安全**:全局安装可能要管理员权限,动系统自带 Python 还可能弄坏系统工具(尤其 Linux);venv 内随便装,不碰系统。

**JS 对照**:npm 默认装进项目 node_modules,天然按项目隔离;pip 默认装全局,所以 Python 要靠 venv 补上这层"项目级隔离"——venv ≈ 项目级 node_modules。大模型项目尤其如此:SDK 迭代快、版本差异大,不同家 SDK 可能依赖不同版本的 httpx/pydantic,全局安装迟早冲突。

## Q2 标准答案
1. **场景:环境就绪自检 + 友好降级**。把 import 放进 try 是在"试探依赖装没装":已装就继续走(打印版本);未装则打印一条可执行的安装指引("请在 venv 内 pip install openai"),而不是让程序带着红色 traceback 当场崩掉。典型场景:①脚本要发给别人/部署到新环境,不能假设依赖已装;②可选依赖,装了某包才启用某功能;③项目启动时的环境自检——本日产物 check_openai() 正是这个用法。
2. **探测的是什么**:当前解释器(当前 venv)的模块搜索路径里**能否找到并加载这个包**,即"这个环境里装没装该 SDK"。不探测:网络通不通、key 有没有效、API 能不能调——那是 day30 之后的事。
3. **为什么用 ImportError 而非 Exception**:精准归因。ImportError 只接"导入失败"这一类错:包括其子类 ModuleNotFoundError(包找不到)、包内名字导不进来等。若用 `except Exception`,包内部语法错误、初始化时的运行错误等真实 bug 也会被当成"没装"吞掉,给出误导性安装提示、掩盖问题。精准捕获 = 精准归因 = 方便定位。

## Q3 标准答案
**list[dict](纯数据派)**
- 优势:零样板、拿来就用;字段可自由增减,不同模型可以有不同字段;天然贴近 JSON,落盘/传输/json.dumps 都方便(day34 会话存档就用)。
- 劣势:**无 schema 约束**——key 拼错(model_name 写成 modle_name)要到运行时才 KeyError,或静默取错数据;没有 IDE 自动补全;数据与行为分离,想加"格式化输出/算性价比"得另写外部函数;字段一多,约定全靠文档,容易漂移。
- 注意:"字段可以不一致"是**双刃剑**——灵活是优势,同时也是"拼错/漏字段没人拦"这一劣势的根源。

**ModelCard 类(对象列表派)**
- 优势:`__init__` 固定字段 schema,漏传/传错实例化时就暴露;可挂行为(`__str__` 统一格式化、校验、对比方法),数据+行为封装在一起;IDE 补全/类型提示友好;适合实体长期复用。
- 劣势:要先定义类,样板代码多;加字段要改类;序列化需额外转换;对"一次性打印对比表"属过度设计。

**本题选了哪种(对照你的产物)**:固定产物实际用的是**嵌套 dict**(dict[str, dict]:key 为厂商名、value 为信息 dict,共 4 家),与 list[dict] 同属纯数据派;extra 跟练则写了 ModelCard + 对象列表——两条路都走过。选择理由看需求:本题要求"组织→遍历打印→落盘",没有实体行为,dict 最省;若未来要给模型卡挂行为(格式化/校验/对比)或长期复用,再升级成类。**一句话原则:纯数据搬运/展示 → dict;schema 稳定 + 要挂行为/长期复用 → class。**

**JS/TS 对照**:dict ≈ 对象字面量/JSON;class ≈ interface + class 的组合——TS 用 interface 约束对象形状,Python 的 dict 没有这层约束,class 才承担该角色。
