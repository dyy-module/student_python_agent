## 闸门附加·Python 与 JS 至少三处差异(硬性)
1. 包管理 venv/pip vs npm 的关键差(手动激活)
    python venv 是环境,有隔离区域，每个环境可以有一个版本，相当于npm 的node版本环境。而node_module是by项目的，相当于python的不同模块。
2. <待填写:类型 typing 运行时不强制 vs TS 编译期强制>
    python typing 不运行，不检测，运行时资源0消耗。 只有使用第三方工具，ide检测时，才有效。
    而ts 是编译时强制检测，如何有错误，无法编辑
3. <待填写:异步 asyncio.run 手动点火 vs JS 事件循环内建>
   asyncio 异步需要单独的触发器，建立事件循环。可以有多个事件循环。每个协程函数，都需要await 触发，否则不执行
   js 本身就是但进程事件循环模式，所以天然适合异步I/O. 只有 await 部分会交给事件循环，上方的代码顺序执行
