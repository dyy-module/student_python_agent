# 验证规则与里程碑

> 本文件定义贯穿17周的整体验证体系:三级验收 + 项目级 + 求职级,以及连贯性/弹性规则和里程碑节点表。所有"通过/未通过"均以本文件量化标准为准。

## 一、三级验证体系
### 日级(每日验收,当天完成)
1. 闭包合规:产物只能用当日及以前已学知识点;附知识点清单;超前内容须标【超前】+最小片段;Day22前禁一切第三方库。教程可为达到真实可用而增补必要知识点("当日首教新知识点≤5"为软上限,见主计划/规则12),但增补项须当日首教当日即用,不得未教先用。
2. 可运行:`python <产物>.py` 直接跑通,每步有print。产物须体现真实度至少一项(非理想输入处理/错误恢复/边界空值/可配置不硬编码/多步组合,2026-11-12 起计入功能完整性评分)。
3. 双向对账(2026-10-24 day21对账日第3次修订,现行口径):index.md 末只写**两行自检**——①「我说不出出处的知识点:…」(没有写"无");②「学了但没落进任何行为的知识点:…」。行为-知识点的对应关系由助教验收时读产物核对,学习者不再誊写行为表。**演化史**:旧4列核对表(学习内容|教材章节|当日产物|所用知识点)于2026-10-10废止——列1/列2零加工誊写、列3助教可读得、列4与列1同构;其后「行为-知识点自证表」(行=行为,3列)的列1/列2 又被证实是同一病的简化版(2026-10-24 学习者反馈"誊写无意义"成立),真信号仅存于上述两行,遂再压缩。口径不变:第①行出现清单外知识点=未教先用须【超前】(三无项除外,不要求留痕);第②行=防"学了没练"。教材参考页仍由教程「教材与章节」段与产物壳【教材·只读N节】给单一出处,学习者不誊写。
4. 行数与命名(2026-11-12 修订):工作日单产物≤120行、周六项目日≤150行、周日/检测≤180行为硬护栏;"当日首教新知识点≤5"降为软上限(适量,任务确需可增补,须当日教当日用并在教程「本日新增」列出标"实战必需";不突破行数护栏);固定产物文件名列死;跟练统一 extra_*.py 放 extra/ 子目录。
5. 笔记:index.md覆盖当日全部学习内容。代码口径(2026-10-10 精确定义):凡标 ` ```python ` 的代码块必须是**纯 Python 且可直接运行**;Python 块内禁出现 JS 语法(如 `//` 注释)。**JS 片段允许**——它是本教程 JS→Python 对照的必要材料,但须单独成块并标注语言(如 ` ```javascript `),不得与 Python 块混写。**`卡点与解决` 属非必填**:留空或写"暂无"不计欠项,验收报告不得据此列待办(规则从未要求填全;该栏价值在写它的当下,不在交检)。(订正说明:旧措辞"代码块纯Python、禁混JS"易被读成"不得存在 JS 块",day15 曾因此误判学习者违规两次——属反模式第7条判罚错配。)

### 周级(周日检测+对账)
1. 限时盲写:不看教材/不看往期产物,限时独立完成综合任务(工作日难度上限≤120行,周六项目日≤150行,周末检测放宽≤180行)。
2. 量化通过标准:每周检测给明确通过线(见里程碑表)。
3. 补救方案:个别错误→当天缓冲订正+次日重盲写;逻辑不通→重做对应day;严重超时(>90min)→本周降级,下周前2天补欠账,闸门顺延不取消。
4. 周日对账4步:①产物清单vs实际目录逐项✅/❌/⚠️;②填README跟踪表(完成%/自评1-5/卡点/补救);③缺1-2项用缓冲日补,缺≥3项下周前2天补欠账;④每个.py必须跑通验收。

### 阶段闸门(day28/42/63/84/98)
综合产物限时完成,过量化通过线方可进入下一阶段(见里程碑表)。

## 二、项目级验证(作品集)
- README验收清单:架构图、成本数据(token/服务器)、真实数据(非mock)、在线可访问URL、技术选型说明。
- 4维度评分(每个产物/项目通用):①功能完整性②闭包合规③行数与命名④代码质量(可读性/边界处理/print输出)。
- 结论格式:通过/部分通过/未通过 + 改进建议 + 次日预告。

## 三、求职级验证
- GitHub:冷启动第4周起步,累计30+→150+ commits。
- 博客:5-8篇掘金/知乎深度文(SSE流式踩坑、前端转AI、Agent工具调用可视化、RAG召回评测)。
- 投递:阶段6初投5个练手→首批10+→密集期周投20-30个精准岗。
- 简历:真实头衔+业务描述+AI项目置顶;通过诚信核查(背调可核对社保/前雇主职位)。

## 四、连贯性与弹性规则
- 最低底线:再忙也完成30min跟练/20行代码/补一段笔记——不断线是唯一目的。
- 中断重启:≤2天按原计划继续;3-5天砍加分项保核心;>5天本周降级补欠账。
- 弹性裁剪:见骨架总表"弹性与裁剪"节。
